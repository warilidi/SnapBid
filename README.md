# skinarb: сигналы о дешёвых лотах CS2 на Skinport

Бот сравнивает новые лоты из live-фида с медианой реальных продаж и пишет в Telegram,
если расчётная прибыль после комиссии выше порога. Покупаете вы сами, по кнопке.

## Запуск (Python 3.11+)

    python -m venv .venv
    source .venv/bin/activate        # Windows: .venv\Scripts\activate
    pip install -r requirements.txt
    cp .env.example .env             # Windows: copy .env.example .env
    pytest
    python main.py

## Настройка
1. Создайте бота у @BotFather и впишите токен в `.env` (`TELEGRAM_BOT_TOKEN`).
2. Проверьте `ADMIN_ID` — это ваш Telegram ID.
3. Запустите `python main.py`, откройте своего бота и нажмите Start.

## Доступ
- Пускает только по ID: администратора и тех, кто вошёл по приглашению.
- `/invite` создаёт одноразовую ссылку на 24 часа. Доступ получает первый, кто нажмёт Start.
  Пересылайте её лично нужному человеку.
- `/users` — список, `/revoke ID` — убрать участника.
- Фильтры `/roi` и `/price` применяются отдельно для каждого пользователя; один пользователь
  при повторном событии может получить уже встречавшийся лот, если он ещё не отправлялся ему
  и его фильтры подходят.
- У каждого свои настройки сигналов: `/pause`, `/resume`, `/settings`.
- В «Площадки и фильтры» каждый пользователь отдельно включает Skinport; он включён
  по умолчанию. Его публичные [API endpoints](https://docs.skinport.com/items) документированы,
  но доступность для оператора из России и регион Wispbyte не подтверждены.
- Статус интеграций (проверены официальные API/условия; доступность сайта в РФ не доказывает
  доступность API из региона сервера):

  | Площадка | Официальный API и ключи | Регион / использование | Статус в боте |
  | --- | --- | --- | --- |
  | Skinport | Публичные `/v1/items` и `/v1/sales/history` без ключа; ключ нужен для API аккаунта. Общий лимит этих endpoints: 8 запросов за 5 минут. | Доступность для оператора из РФ и регион Wispbyte не подтверждены. | Текущая интеграция, включена по умолчанию. |
  | DMarket | Подписанный API; `DMARKET_API_KEY` и `DMARKET_SECRET_KEY`. | [Условия](https://dmarket.com/terms-of-use) перечисляют жителей РФ и Беларуси среди лиц, которым может быть запрещён доступ. | Отключён: кнопки и фильтры убраны, polling не запускается. |
  | Waxpeer | Официальная [документация REST/Socket.IO](https://docs.waxpeer.com/socketio) описывает live feed с ID лота; снимки поддерживают CSV. | В доступной редакции условий (11.11.2022) есть ограничения на коммерческое использование контента и извлечение данных; их соотношение с API-сценариями агрегаторов неясно. Общий запрет для РФ не найден, но доступность аккаунта/API-сервера не подтверждена. | Не подключён до уточнения разрешений и региональной доступности. |
  | BitSkins | Официальная [страница API v2](https://bitskins.com/docs/api/v2), но доступная страница не раскрывает схему API. | Условия и доступность API для РФ/региона сервера не подтверждены. | Не подключён. |
  | CSFloat | Официальную схему API не удалось проверить; документационный хост недоступен при проверке. | Условия для РФ не подтверждены. | Не подключён. |
  | BUFF163 | Публичный официальный API выдачи лотов не подтверждён. | Условия и доступ из РФ не подтверждены. | Не подключён. |
  | SkinBaron | Страница API не раскрывает схему без загрузки SPA. | Условия для РФ не подтверждены. | Не подключён. |
  | GamerPay | Официальный публичный API выдачи лотов не подтверждён. | Сведения справочного центра о платёжных ограничениях не удалось проверить по доступной первичной статье. | Не подключён. |

  Неизвестная страна пользователя Telegram не угадывается. Steam Community Market и другие
  сайты без документированного разрешённого listing API не скрейпятся.
- Для будущих адаптеров нативный лот нормализуется в `MarketplaceSignal`; общий роутер применяет
  настройки, диапазоны цены/float и дедупликацию отдельно по provider и каждому пользователю.
  Специфичные для Skinport история/ROI остаются в отдельном пути.
- `/start` открывает меню с кнопками статуса и настроек; администратору доступна панель
  управления участниками и приглашениями. Кнопки повторно проверяют права и текущий доступ.

Бот работает, пока запущен `main.py`. Для работы 24/7 нужен сервер (VPS).

## Оплата Telegram Stars
Включена по умолчанию: `STARS_PRICE=400` (0 выключает). Покупатель отправляет `/buy`,
соглашается с `/terms` и платит; доступ на `SUB_DAYS` дней открывается сам.
Вам приходит сообщение с командой `/refund КОД`: она возвращает звёзды и списывает дни.
Перед запуском включите двухэтапную проверку на своём аккаунте Telegram и прочитайте
текст `/terms` в `stars.py`. Файл `signals.db` хранит платежи: делайте копии.

## Продажа подписки
Новый человек видит цену (цена `SUB_PRICE`, срок `SUB_DAYS`), контакт `SALES_CONTACT` и свой ID.
Получив оплату, администратор отправляет боту `/sub ID`; повторная команда продлевает срок.
Команда есть только у `ADMIN_ID`. `/revoke ID` закрывает доступ.

## Оплата через Crypto Bot
1. В @CryptoBot откройте Crypto Pay, создайте приложение и получите API-токен.
2. Впишите в `.env`: `CRYPTO_PAY_TOKEN`, `SUB_PRICE`, `SUB_ASSET`, `SUB_DAYS`.
3. Перезапустите бота.

С включённой оплатой купить доступ может любой, кто открыл бота. Приглашения `/invite`
дают бесплатный бессрочный доступ. `/revoke` блокирует ID, и платеж не восстановит доступ;
блокировку снимает только новое приглашение или явная команда администратора `/sub ID`.
Если оплата Stars успела пройти одновременно с блокировкой, бот попытается вернуть звёзды;
при неудаче администратору придёт команда для ручного возврата. Оплата Crypto Bot за
заблокированный ID не открывает доступ — администратору нужно проверить возврат.
Оплата проверяется каждые 10 секунд; если бот был выключен, зачтётся после запуска.
Возвраты Crypto Bot делаются вручную. Для теста используйте @CryptoTestnetBot и
`CRYPTO_PAY_URL=https://testnet-pay.crypt.bot`; боевой и тестовый режимы держите
на разных базах (`DB_PATH`).

**Важно:** по правилам Telegram цифровые товары в ботах продаются только за Stars.
При оплате криптой Telegram может перестать показывать бота на телефонах.

## Статистика
    python report.py

Через 7 дней после сигнала бот сравнивает цену покупки с новой 7-дневной медианой.
Пока средний и медианный ROI не положительны на сотнях сигналов, подписку не продавайте.

## Ограничения
- Float, паттерн и наклейки в оценке не учитываются.
- Медиана не гарантирует, что предмет продастся по этой цене.
- Ссылка на конкретный лот строится по `saleId` (`/item/<url>/<saleId>`) или, если его нет, по Skinport `assetid` (`/a/<assetid>`). Если оба ID отсутствуют, лот не отправляется.
- DMarket предоставляет цену в USD и optional float, но не подтверждённые в этой интеграции
  поля исторического объёма, комиссии или точного URL объявления; эти значения не выдумываются.
- Комиссию (`FEE`) сверяйте на сайте.
- `MIN_ROI=0.10` при комиссии 8% означает скидку к медиане около 16%.
- Пороги цен и прибыли заданы в валюте `CURRENCY`.
- Перед платной раздачей сигналов прочитайте условия Skinport.
