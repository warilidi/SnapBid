# skinarb: сигналы о дешёвых лотах CS2 на Skinport

Бот сравнивает новые лоты из live-фида с медианой реальных продаж и пишет в Telegram,
если расчётная прибыль после комиссии выше порога. Покупаете вы сами, по кнопке.

## Запуск (Python 3.11+)

    python -m venv .venv
    source .venv/bin/activate        # Windows: .venv\Scripts\activate
    pip install -r requirements.txt
    cp .env.example .env             # Windows: copy .env.example .env
    pytest
    python main.py

## Настройка
1. Создайте бота у @BotFather и впишите токен в `.env` (`TELEGRAM_BOT_TOKEN`).
2. Проверьте `ADMIN_ID` — это ваш Telegram ID.
3. Запустите `python main.py`, откройте своего бота и нажмите Start.

## Доступ
- Пускает только по ID: администратора и тех, кто вошёл по приглашению.
- `/invite` создаёт одноразовую ссылку на 24 часа. Доступ получает первый, кто нажмёт Start.
  Пересылайте её лично нужному человеку.
- `/users` — список, `/revoke ID` — убрать участника.
- У каждого свои настройки: `/roi`, `/price`, `/pause`, `/resume`, `/settings`.
- `/start` открывает меню с кнопками статуса и настроек; администратору доступна панель
  управления участниками и приглашениями. Кнопки повторно проверяют права и текущий доступ.

Бот работает, пока запущен `main.py`. Для работы 24/7 нужен сервер (VPS).

## Оплата Telegram Stars
Включена по умолчанию: `STARS_PRICE=400` (0 выключает). Покупатель отправляет `/buy`,
соглашается с `/terms` и платит; доступ на `SUB_DAYS` дней открывается сам.
Вам приходит сообщение с командой `/refund КОД`: она возвращает звёзды и списывает дни.
Перед запуском включите двухэтапную проверку на своём аккаунте Telegram и прочитайте
текст `/terms` в `stars.py`. Файл `signals.db` хранит платежи: делайте копии.

## Продажа подписки
Новый человек видит цену (цена `SUB_PRICE`, срок `SUB_DAYS`), контакт `SALES_CONTACT` и свой ID.
Получив оплату, администратор отправляет боту `/sub ID`; повторная команда продлевает срок.
Команда есть только у `ADMIN_ID`. `/revoke ID` закрывает доступ.

## Оплата через Crypto Bot
1. В @CryptoBot откройте Crypto Pay, создайте приложение и получите API-токен.
2. Впишите в `.env`: `CRYPTO_PAY_TOKEN`, `SUB_PRICE`, `SUB_ASSET`, `SUB_DAYS`.
3. Перезапустите бота.

С включённой оплатой купить доступ может любой, кто открыл бота. Приглашения `/invite`
дают бесплатный бессрочный доступ. `/revoke` блокирует ID, и платеж не восстановит доступ;
блокировку снимает только новое приглашение или явная команда администратора `/sub ID`.
Если оплата Stars успела пройти одновременно с блокировкой, бот попытается вернуть звёзды;
при неудаче администратору придёт команда для ручного возврата. Оплата Crypto Bot за
заблокированный ID не открывает доступ — администратору нужно проверить возврат.
Оплата проверяется каждые 10 секунд; если бот был выключен, зачтётся после запуска.
Возвраты Crypto Bot делаются вручную. Для теста используйте @CryptoTestnetBot и
`CRYPTO_PAY_URL=https://testnet-pay.crypt.bot`; боевой и тестовый режимы держите
на разных базах (`DB_PATH`).

**Важно:** по правилам Telegram цифровые товары в ботах продаются только за Stars.
При оплате криптой Telegram может перестать показывать бота на телефонах.

## Статистика
    python report.py

Через 7 дней после сигнала бот сравнивает цену покупки с новой 7-дневной медианой.
Пока средний и медианный ROI не положительны на сотнях сигналов, подписку не продавайте.

## Ограничения
- Float, паттерн и наклейки в оценке не учитываются.
- Медиана не гарантирует, что предмет продастся по этой цене.
- Формат ссылки на лот (`/item/<url>/<saleId>`) в документации не описан: проверьте кнопку.
- Комиссию (`FEE`) сверяйте на сайте.
- `MIN_ROI=0.10` при комиссии 8% означает скидку к медиане около 16%.
- Пороги цен и прибыли заданы в валюте `CURRENCY`.
- Перед платной раздачей сигналов прочитайте условия Skinport.
